# Majority Element

The **majority element** is the element that appears more than `n / 2`
times in an array, where `n` is the size of the array.

**Example:**

``` cpp
vector<int> nums = {2, 2, 1, 1, 1};
```

The majority element is `1` because it appears 3 times in an array of 5
elements.

------------------------------------------------------------------------

## 1. Brute Force Approach

**Time Complexity:** `O(n²)`\
**Space Complexity:** `O(1)`

Check the frequency of every element by traversing the array again.

``` cpp
int n = nums.size();

for (int val : nums) {
    int freq = 0;

    for (int el : nums) {
        if (el == val) {
            freq++;
        }
    }

    if (freq > n / 2) {
        return val;
    }
}
```

**How it works:** - Select each element as `val`. - Count how many times
it appears in the array. - If its frequency is greater than `n / 2`,
return it.

------------------------------------------------------------------------

## 2. Sorting Approach

**Time Complexity:** `O(n log n)`\
**Space Complexity:** Depends on the sorting implementation.

After sorting, equal elements appear next to each other. Count
consecutive equal elements to find the majority.

``` cpp
sort(nums.begin(), nums.end());

int n = nums.size();
int freq = 1;
int ans = nums[0];

for (int i = 1; i < n; i++) {
    if (nums[i] == nums[i - 1]) {
        freq++;
    } else {
        freq = 1;
        ans = nums[i];
    }

    if (freq > n / 2) {
        return ans;
    }
}

return ans;
```

**How it works:** - Sort the array. - Count consecutive occurrences of
each element. - Return the element when its frequency becomes greater
than `n / 2`.

> This implementation assumes the array is non-empty and that a majority
> element exists.

------------------------------------------------------------------------

## 3. Moore's Voting Algorithm

**Time Complexity:** `O(n)`\
**Space Complexity:** `O(1)`

Moore's Voting Algorithm finds a majority-element candidate by
maintaining a frequency counter.

``` cpp
int freq = 0;
int ans = 0;

for (int i = 0; i < nums.size(); i++) {
    if (freq == 0) {
        ans = nums[i];
    }

    if (nums[i] == ans) {
        freq++;
    } else {
        freq--;
    }
}

return ans;
```

**How it works:** - When `freq` is `0`, choose the current element as
the candidate. - If the current element matches the candidate, increment
`freq`. - Otherwise, decrement `freq`. - After the loop, `ans` holds the
majority-element candidate.

### Important: Verify the Candidate

Moore's Voting Algorithm finds a candidate, but it does not prove that
the candidate appears more than `n / 2` times. If the problem does not
guarantee that a majority element exists, verify it:

``` cpp
int count = 0;

for (int el : nums) {
    if (el == ans) {
        count++;
    }
}

if (count > nums.size() / 2) {
    return ans;
}

return -1; // No majority element
```

------------------------------------------------------------------------

## Approach Comparison

  Approach                     Time Complexity   Space Complexity
  -------------------------- ----------------- ------------------
  Brute Force                          `O(n²)`             `O(1)`
  Sorting                         `O(n log n)`    Depends on sort
  Moore's Voting Algorithm              `O(n)`             `O(1)`

**Best approach:** Moore's Voting Algorithm, because it takes linear
time and constant extra space.
